Guide for teachers & students

How to add an API key

There are 2 ways to use KawanCakap:

✅ Option 1: Class code (no key needed)

If your teacher gave you a class code, you don't need any key. Choose Class code, type the 6-letter code and start. It's free, with a daily limit per student.

Teachers: create a class on the Teacher page and share the code or the WhatsApp link with your students.

🔑 Option 2: Your own API key

Use your own key when you don't have a class code, when the class's free sessions for today are used up, or when you want unlimited practice. Each person uses their own key on their own phone.

⭐ Gemini key: free, no card needed (recommended)
  1. Open aistudio.google.com/apikey and sign in with a Google account (Gmail).
  2. Accept the terms if it asks.
  3. Tap Create API key. If it asks for a project, choose the default one or tap Create project.
  4. Tap Copy. The key starts with AIza….
  5. Open KawanCakap, choose My Gemini key, paste the key in API key and tap Start practice.

The free tier has a daily limit from Google. If you see "rate limit", wait a few minutes or try again tomorrow. Students under 18 may need a parent's Google account.

OpenAI key: paid, best voice

A ChatGPT Plus subscription does not include API access. The API is paid separately, pay as you go.

  1. Open platform.openai.com and log in (your ChatGPT account works).
  2. Go to Settings → Billing and add credit (usually at least US$5, card needed). Without credit the key won't work.
  3. Go to Settings → Limits and set a monthly budget so you're never surprised.
  4. Open platform.openai.com/api-keys and tap Create new secret key. Name it kawancakap.
  5. Copy it straight away. It starts with sk-… and is shown only once.
  6. Open KawanCakap, choose My OpenAI key, paste it and tap Start practice.

🔒 Keep your key safe

  • Your key is saved only on your own phone or computer. KawanCakap sends it to Google/OpenAI for each turn and never stores it.
  • Don't share your key in WhatsApp groups or with classmates. Anyone with your key can use your quota or credit.
  • Teachers: don't give students your own paid key. Use a class code instead.
  • If a key leaks, delete it on the same page where you created it, then make a new one.

Problems?

"Your API key was rejected"
The key was copied wrongly or deleted. Copy it again, with no spaces before or after.
"Rate limit or no credit left"
Gemini: wait a bit or try tomorrow. OpenAI: add credit under Billing.
"Gemini keys start with AIza" / "OpenAI keys start with sk-"
You chose the wrong option. Pick the one that matches your key.
Using a new phone
Paste the key again. Keys are saved per device.
